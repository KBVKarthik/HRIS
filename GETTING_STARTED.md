## 🔧 Troubleshooting

### Issue: Page won't load

**Solution:**

1. Check if backend is running (should see "HRIS Backend running on port 5000" in terminal)
2. Check if frontend is running (should see "Compiled with warnings" in terminal)
3. Try refreshing browser (F5 or Ctrl+R)
4. Close and reopen browser

### Issue: Demo data won't populate

**Solution:**

1. Make sure you're logged in
2. Check that you have admin permissions
3. Try again - might have been database timeout
4. Check backend terminal for error messages
5. Restart both servers

### Issue: Can't login

**Solution:**

1. Make sure you created account first (register)
2. Double-check email and password
3. No spaces before/after email
4. Password is case-sensitive
5. Try creating a new account

### Issue: Charts not showing

**Solution:**

1. Refresh page (F5)
2. Make sure demo data is populated
3. Check browser console for errors (F12)
4. Try logging out and back in
